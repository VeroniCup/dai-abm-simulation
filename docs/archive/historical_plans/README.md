implemented domain-first repository and current empirical methodology.

[data acquisition plan](DATA_ACQUISITION_PLAN.md) retains the original and
revised chronological acquisition rationale. Current acquisition instructions
are in [the active acquisition guide](../../data/acquisition.md).

The [structure snapshot](structure_snapshot.txt) records an earlier repository
layout. Use the current [repository guide](../../overview/repository_guide.md)
for navigation.
