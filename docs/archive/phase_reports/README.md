# Phase reports

These reports preserve bounded acquisition, estimation and review milestones.
Their phase labels, generated-output locations and command paths are historical
evidence. Use the active [calibration index](../../calibration/README.md) and
[data guides](../../data/acquisition.md) for current instructions.

The archive includes representative vault acquisitions, parameter estimation
and candidate reviews. Reports are retained without rewriting their numerical
results or methodological limitations.
